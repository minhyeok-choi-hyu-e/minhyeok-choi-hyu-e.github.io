연구 분야

AI 에이전트 기반 설계 자동화

대형 언어 모델(LLM) 기반 에이전트가 설계 요구조건 해석부터 형상 제안, 검토까지의 과정을 스스로 수행하도록 하는 방법을 공부하고 있습니다. 현재 IDEA Lab에서 진행 중인 주 관심 주제입니다.

Keywords: LLM Agent 설계 자동화 Python

AI 에이전트 기반 드론 설계

임무 요구조건에 맞는 드론의 형상과 구성을 LLM 에이전트가 제안하고 스스로 검토하도록 하는, 설계 자동화 연구를 적용하는 대상 시스템으로 드론을 다루고 있습니다.

Keywords: LLM Agent 드론 설계 형상 설계

기계 설계 · 해석 (CAD / CAE)

3D 모델링과 구조·유동 해석을 통해 설계안을 직접 만들고 검토하는 역량을 쌓고 있습니다.

Keywords: 3D CAD 구조 해석 유동 해석

연구 및 프로젝트

AI 에이전트 기반 드론 설계 자동화

LLM 에이전트가 임무 요구조건을 입력받아 드론의 형상과 구성을 제안하고, 그 결과를 스스로 검토하도록 하는 설계 자동화 파이프라인을 IDEA Lab에서 연구하고 있습니다. 상세 내용과 결과는 진행에 따라 업데이트할 예정입니다.
